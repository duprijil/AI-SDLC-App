Agent harness harness/claude-code.yaml

tool: claude-code # the real CLI, installed in the image session: { per: ticket, cwd: /workspaces/{{ticket.key}} } launch: claude --session-id {{session.id}} resume: claude --resume {{session.id}} inject: { mcp: sdlc, instructions: CLAUDE.md ← guardrails.md } observe: hooks: [SessionStart, PreToolUse, Notification, Stop] control: { send: bracketed-paste, interrupt: Esc } policy: { deny: ["Bash(gh pr merge*)", "mcp__atlassian__*write*"] }

Guardrails guardrails.md → CLAUDE.md in each workspace

- No comments in code. - Unit tests are written after manual testing. - Draft PR, Jira and PM texts with sdlc.draft. Never post them. - Never merge, promote or move tickets. The human does that from the board.
